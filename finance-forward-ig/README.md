# Finance Forward Instagram assets

Slide images for @financeforward_1, hosted here so Buffer can fetch them by public link.
One folder per Substack post slug: `<slug>/piece.json`, `1.png`, `2.png`, `3.png`.
`build_carousel.py piece.json <slug>/` renders the three slides (needs Pillow and rsvg-convert).
A folder for a slug means that post already has its carousel; do not rebuild it.
Raw URL pattern: https://raw.githubusercontent.com/AbhiPrakash10/AbhiPrakash10.github.io/finance-forward-ig/finance-forward-ig/<slug>/1.png
