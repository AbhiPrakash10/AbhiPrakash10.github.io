# Finance Forward article documentation

One folder per published article, named `<date>-<column>-<topic>`:
- `article.md`: the text as it left the fact-check, with sources, disclosure and footer
- `ledger.md`: the numbers ledger (every figure, sourced or derived) and the checks run

Images and their build spec live in `article-images/<name>/`. Do not put article folders under `finance-forward-ig/`; the Instagram task treats every folder there as a finished carousel.

This repository is public. Private working notes (status checklists, the sensitive-names check, trading windows) stay in the Claude project and are not saved here.
